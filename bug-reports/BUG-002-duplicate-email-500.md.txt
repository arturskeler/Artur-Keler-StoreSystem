# BUG-002: Необработанное исключение базы данных (IntegrityError) при дублировании email

## 📌 Описание
При попытке обновить данные пользователя в `PUT /users/edit/{id}` с указанием email, который уже принадлежит другому пользователю, база данных выбрасывает исключение уникальности (`IntegrityError`). Бэкенд не обрабатывает данное исключение и падает с кодом `500 Internal Server Error`.

## 🛠 Шаги воспроизведения (Steps to Reproduce)
1. Открыть Postman и выбрать запрос `PUT [400] Edit User - Duplicate Email`.
2. Указать валидный `targetUserId` в пути.
3. В Body передать email, который уже закреплен за другим аккаунтом.
4. Передать валидный токен авторизации и нажать Send.

## ✅ Ожидаемый результат (Expected Result)
Сервер должен вернуть статус `400 Bad Request` или `409 Conflict` с понятным сообщением об ошибке.

## ❌ Фактический результат (Actual Result)
Сервер возвращает статус `500 Internal Server Error`.

## 🔍 Окружение
* **Среда:** Docker / FastAPI / PostgreSQL
* **Версия:** Release 1 (Authorization API)
