# 🛒 Store Manager — QA Portfolio Project

Комплексный проект по ручному и автоматизированному тестированию бэкенда и API микросервисной системы управления складами (**Store Manager**).

## 🛠 Стек технологий и инструментов
* **API Testing & Management:** Postman, REST API
* **Test Management:** TestIT
* **Environment:** Docker, FastAPI, PostgreSQL
* **Version Control:** Git / GitHub

---

## 📦 Релиз 1 — Авторизация и Управление пользователями (RestAPI)

На первом этапе проводилось функциональное тестирование эндпоинтов управления пользователями (просмотр, редактирование, удаление, назначение ролей) и проверка системы разграничения прав доступа (RBAC).

### 📊 Результаты тестирования
* **Всего тест-кейсов:** 16
* **Пройдено (Passed):** 13 (включая корректную работу RBAC с ответом `403 Forbidden`)
* **Провалено (Failed / Дефекты):** 3 (выявлены критические ошибки бэкенда с возвратом `500` вместо кодов валидации)

### 🔴 Найденные критические дефекты
1. **[BUG-001] Падение сервера (500) при передаче невалидного UUID** в эндпоинтах `PUT /users/edit/{id}` и `DELETE /users/delete/{id}` вместо ожидаемого `422 Unprocessable Entity`.
2. **[BUG-002] Необработанное исключение базы данных (500)** при попытке установить дубликат email в `PUT /users/edit/{id}` вместо `400 Bad Request` / `409 Conflict`.

## 🚀 Как запустить коллекцию в Postman
1. Скачайте файлы из папки `postman/`.
2. Импортируйте коллекцию `Store_Manager_Collection.json` и файл окружения `Store_Manager_Environment.json` в Postman.
3. Задайте локальный адрес `baseUrl` (например, `http://localhost:8000`) и актуальные токены/ID в переменных окружения.
